The stage of the underlying model. This enum is not supported in Vertex AI.

[JsonConverter(typeof(JsonStringEnumConverter))]
public enum ModelStage

Fields

[JsonPropertyName("DEPRECATED")] DEPRECATED = 6

Models in this stage are deprecated. These models cannot be used.

[JsonPropertyName("EXPERIMENTAL")] EXPERIMENTAL = 2

Models in this stage are for experimental purposes only.

[JsonPropertyName("LEGACY")] LEGACY = 5

If the model is on this stage, it means that this model is on the path to deprecation in near future. Only existing customers can use this model.

[JsonPropertyName("MODEL_STAGE_UNSPECIFIED")] MODEL_STAGE_UNSPECIFIED = 0

Unspecified model stage.

[JsonPropertyName("PREVIEW")] PREVIEW = 3

Models in this stage are more mature than experimental models.

[JsonPropertyName("RETIRED")] RETIRED = 7

Models in this stage are retired. These models cannot be used.

[JsonPropertyName("STABLE")] STABLE = 4

Models in this stage are considered stable and ready for production use.

[JsonPropertyName("UNSTABLE_EXPERIMENTAL")] UNSTABLE_EXPERIMENTAL = 1

The underlying model is subject to lots of tunings.
